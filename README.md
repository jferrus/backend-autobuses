# Backend Autobuses
El propósito de esta aplicación es de adquirir habilidad y si procede, vender servicios de instalación, configuración y puesta en marcha de este programa.

## Entorno de programación
Node.js

## Protocolo
Servicio basado en REST con el el protocolo HTTP.

## Lenguaje de programación principal
Javascript, ECMASScript2024

## Base de datos
SQLite

## Testing
Test runner nativo de Node.js.
